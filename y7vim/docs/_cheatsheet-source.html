y7vim cheatsheet

LazyVim + Claude Code

<leader> = Space

Press Space, release, then the next key(s). Press Space alone and wait: which-key shows every option.

Files & search

<leader>eToggle file explorer
<leader>ffFind file by name
<leader><space>Find file (quick)
<leader>fgSearch in files (grep)
<leader>frRecent files

Buffers & windows

<leader>bdClose buffer
Tab / S-TabNext / prev buffer
<leader>-Split window below
<leader>|Split window right
C-h/j/k/lMove between windows

LSP (hover a symbol first)

gdGo to definition
grGo to references
KHover docs
<leader>caCode action
<leader>crRename symbol
<leader>cfFormat buffer

Claude Code chat (claudecode.nvim)

<leader>acToggle Claude terminal
<leader>abAdd buffer to context
<leader>afFocus Claude terminal
<leader>arResume previous session
<leader>aCContinue last conversation
<leader>aaAccept proposed diff
<leader>adDeny proposed diff

Claude config TUI (lazyclaude.nvim)

<leader>lcOpen LazyClaude TUI

Terminal / git

<leader>ggOpen lazygit
C-/Toggle terminal

Modes (bottom-left status)

NORMALMove / run commands (Esc to enter)
INSERTTyping text (i to enter)
VISUALSelect text (v to enter)
